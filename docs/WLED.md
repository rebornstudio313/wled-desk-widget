# Интеграция WLED

## Первичные источники

- https://kno.wled.ge/interfaces/json-api/
- https://kno.wled.ge/features/presets/
- https://kno.wled.ge/interfaces/websocket/
- https://kno.wled.ge/interfaces/udp-notifier/
- https://kno.wled.ge/features/settings/

API нужно проверить на каждой поддерживаемой версии. Начальная целевая матрица
WLED 0.14 / 0.15 / 16.x является **планом проверок**, не заявленной совместимостью.
ESP8266 и ESP32, разные число LED и цветовые возможности — отдельные случаи.

## Чтение

| Ресурс | Назначение |
|---|---|
| GET /json/info | версия, имя, идентификация, LED count, live/realtime |
| GET /json/state | текущее состояние и сегменты |
| GET /json/eff | список эффектов конкретного устройства |
| GET /json/fxdata | метаданные эффектов при поддержке прошивкой |
| GET /json/pal | имена палитр |
| GET /presets.json | пресеты и плейлисты устройства |
| WS /ws | подписка на изменения; fallback на опрос |

Недоступный необязательный ресурс не делает устройство полностью неподдерживаемым.
Вместо выдуманных параметров — ограниченный режим и понятная отметка в UI.

## Запись

POST /json/state с минимальным patch. Примеры:

```json
{"on":true,"bri":128}
```

```json
{"seg":[{"id":0,"col":[[0,187,255]],"fx":0}]}
```

```json
{"ps":4}
```

Перед созданием/удалением пресетов проверить psave/pdel и именование по официальному
API целевой версии. Не редактировать весь presets.json для простой смены цвета.
Для обычной команды не отправлять весь ранее считанный state обратно.
Яркость 0 в UI обрабатывать как выключение, сохраняя последнюю ненулевую яркость.

## Идентификаторы и группы

Каталог хранит device-local numeric ID и отображаемое имя. Групповое применение
эффекта разрешается только после разрешения ID отдельно на каждом устройстве.
Если имена неоднозначны или метаданные несовместимы — запрос сопоставления,
а не случайный выбор. Каталог пресетов в группе показывает устройство-источник.
Групповая сцена хранит отдельные presetId для каждой лампы.

Не копировать stop/start сегментов между лентами разной длины. Переносимую сцену
цвета/эффекта отделять от аппаратной топологии и назначения сегментов.

## Чужие изменения и внешние потоки

После изменения в телефоне обновлять reported state. Если источник realtime
перекрывает внутренние эффекты WLED, показывать это свойство устройства.
Нет интеграции с какой-либо RGB-программой; виджет не знает её процессов и API.
DDP-рендер/потоковая подсветка не нужны для управления встроенными эффектами WLED.

## Настройки и резервные копии

Профиль виджета и полная конфигурация контроллера — разные форматы.
Чтение/запись /json/cfg, экспорт cfg.json и восстановление пресетов — расширенный
этап после проверки версий и доступности. Полный backup считается приватным.
До записи показать diff, предупреждение о возможном разрыве связи и способ восстановления.
Не публиковать backup и не переносить Wi-Fi/GPIO с одной лампы на другую автоматически.
Для неподдерживаемых полей открывать родную страницу настроек WLED.
