# WLED Desk | Widget 0.1.0-alpha.1

Первая экспериментальная версия. Готовность нативного установщика: [BUILD-STATUS.md](BUILD-STATUS.md).

- Локальный реестр WLED-устройств, автоматическая загрузка при запуске.
- Цвет, HEX, яркость, эффекты, скорость и интенсивность.
- Индивидуальные сценарии Работа/Вечер/Кино из пресетов и своих параметров.
- Две полосы Peek и компактный режим.
- Иконка Спектр; нативный трей включён в исходники.

Ограничения: RGB первого сегмента для своих параметров, один клиент Peek на лампу,
раздельные профили native/preview. Установщик без цифровой подписи. Нативные проверки
и результаты установки перечисляются в статусе сборки, не подразумеваются автоматически.
