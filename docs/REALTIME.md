# Актуальное состояние WLED

Виджет открывает наблюдающее WebSocket-соединение `/ws` к каждой добавленной
лампе и принимает JSON `state`/`info`. Изменения с телефона, кнопки или расписания
обновляют питание, яркость, цвет, эффект, скорость и интенсивность в интерфейсе.
Наблюдение не отправляет команды изменения света и не распространяет внешние
изменения на другие лампы. Копирование выполняется только кнопкой «Все лампы».

Для группы раздельно показываются разные яркость, цвет, эффект, скорость и
интенсивность. Эффекты сравниваются по названию, а не по номеру на контроллере.
Выбор отдельной лампы показывает её собственное состояние.

При обрыве поток переподключается с увеличением задержки до 10 секунд.
HTTP-опрос раз в 5 секунд остаётся резервным и обновляет каталоги эффектов/пресетов.
Поздний HTTP-ответ не заменяет уже полученное более новое потоковое состояние.
Состояние продолжает обновляться в мини-режиме. Реальные кадры эффекта отображает
Peek, когда он включён. Ползунки и цветовое кольцо показывают настройки эффекта,
а не меняют цвет каждого кадра анимации.

В текущей реализации состояние и Peek используют отдельные соединения: одно
для состояния и ещё одно при включённом Peek. Оба края Peek делят один поток.
Сборки WLED с отключённым WebSocket используют резервный HTTP-опрос.

Проверки: tests/integration/realtime-smoke.mjs моделирует изменения с другого
клиента, разные эффекты группы, мини-режим, обрыв/переподключение и отсутствие
обратных команд. Тесты используют изолированные HTTP/WS-лампы.
