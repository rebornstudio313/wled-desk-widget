# Обнаружение WLED в сети

В настройках, перед ручным вводом адреса, находится «Лампы в вашей сети». Поиск запускается при первом открытии настроек; «Повторить поиск» обновляет результаты. Лампы не добавляются автоматически: нажмите ＋ возле найденного устройства. Подключённые лампы не предлагаются повторно. Ручное добавление по IP или имени .local сохраняется.

Windows-версия использует mDNS/DNS-SD `_wled._tcp.local.` и сведения `/json/nodes` от уже зарегистрированных ламп. Адреса проверяются чтением `/json/si`; подсветка, прошивка и настройки контроллеров не изменяются. Поиск ограничен локальными IPv4-адресами, работает ограниченное время и не перебирает всю подсеть. Имя, версия, количество LED и идентификатор берутся с контроллера; уже заданное пользовательское имя сохраняется. Дубли от разных интерфейсов объединяются по MAC, при его отсутствии — по адресу.

Если mDNS отключён на контроллере, блокируется сетью или лампы изолированы друг от друга, автоматический поиск может не найти устройство. Введите его адрес вручную. Адреса не передаются в облако и не включаются в публичные исходники. Поиск выполняется один раз при первом открытии настроек, а затем по кнопке; постоянного фонового сканирования нет.

Источники: [объявление mDNS в WLED](https://github.com/wled/WLED/blob/main/wled00/wled.cpp), [JSON API WLED](https://kno.wled.ge/interfaces/json-api/), [mdns-sd](https://docs.rs/mdns-sd/0.21.1/mdns_sd/).
