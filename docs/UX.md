# Интерфейс

## Утверждённый визуальный ориентир

`assets/design/selected-reference.png`: выбранный вариант 03 «Вкладки».
Тёмное полупрозрачное стекло, голубой контур, аккуратный фиолетовый акцент,
компактные элементы. Это референс, не готовый скриншот приложения.

**Утверждённая граница продукта:** виджет только для WLED. Не добавлять
переключатель или упоминания других RGB-программ. Свободное место в заголовке
занять названием группы/виджета и кнопкой настроек. Обновлённый production-макет
появится при реализации UI, исходное изображение сохранить как референс.

## Компоновка

- Заголовок: «Мои лампы», статус соединения, настройки, питание выбранных целей.
- Выбор: «Все лампы», группы, отдельные устройства. Больше двух — прокручиваемый
  список/поповер без разрастания ширины окна.
- Вкладка «Цвет»: круг выбора цвета, HEX, яркость и быстрые избранные цвета.
- Вкладка «Эффекты»: выбор эффекта, поиск/избранное, палитра, только применимые
  скорость/интенсивность и дополнительные параметры.
- Быстрые слоты «Работа», «Вечер», «Кино» доступны независимо от вкладки.
- Раскрывающаяся панель: пресеты, плейлисты, сегменты, управление группами.
- Отдельное окно настроек: список адресов, импорт/экспорт, параметры приложения,
  сведения WLED и кнопка «Все настройки WLED» во внешнем браузере.

## Состояния

Первый запуск без ламп; проверка адреса; соединение; ошибка; нет сети;
часть группы офлайн; смешанная яркость; несовместимый эффект; загрузка каталога;
пресетов нет; изменение ещё не подтверждено; внешний realtime-поток активен.
Ни один из этих случаев не скрывать под постоянно зелёной точкой.

## Поведение окна

Минимальный размер выбрать после проверки на 100/125/150/200% DPI. Не фиксировать
мелкий текст ради буквального совпадения с картинкой. Положение восстанавливать
на существующем мониторе; если монитор отключён, вернуть окно в видимую область.
Drag только за свободную область заголовка. Закрытие и сворачивание в трей
настраиваются явно. Всегда поверх окон — опция пользователя.

## Доступность

Клавиатурный фокус, подписи для screen reader, числовой ввод рядом с ползунками,
достаточный контраст, отключение анимаций, управление цветом без одного лишь круга.
Все строки в локализации; названия эффектов WLED сохраняются без подмены смысла.
