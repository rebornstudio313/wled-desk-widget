# Peek: предпросмотр лент по краям

## Как использовать

Нажмите кнопку с глазом **Peek** в нижней строке главного окна. Появятся две
узкие цветные полосы на левом и правом краях. В этой же строке выберите источник
для каждого края. При одной лампе оба края показывают её, при двух — по одной.
Можно выбрать любую добавленную лампу, включая третью и последующие. Смена выбора
лампы в основной панели сбрасывает источники к выбранной лампе / первым двум в группе.

Порядок светодиодов: от начала ленты сверху к концу снизу. Длинная лента сжимается
в доступную высоту; это обзор, а не физическая схема расположения диодов. Для матрицы
пиксели разворачиваются в последовательность, а не отображаются сеткой 2D.

Повторное нажатие выключает Peek. При скрытии страницы потоки приостанавливаются.
Сохранение переключателя и источников между перезапусками относится к будущему полному профилю.

## Подключение и ограничения

- Используется реальный поток `ws://адрес/ws` с единственной командой `{"lv":true}`.
  Для HTTPS-прокси используется WSS, ошибки TLS не обходятся.
- Бинарные версии 1 (лента), 2 (матрица), а также старые текстовые сообщения `leds`.
  Неверные/пустые/слишком большие кадры игнорируются.
- Цвета берутся из кадров WLED; цвет выбранной кнопки или название эффекта не
  подменяют предпросмотр. Это программное представление, не измерение цвета глазами.
- WLED отдаёт Peek одному клиенту на лампу. Открытие другого Peek может остановить
  кадры в виджете; через 5 секунд полоса гаснет и появляется объяснение. Виджет не
  перехватывает поток повторными командами. Для явного повторного запроса выключите
  и включите Peek. Сетевые разрывы переподключаются с задержкой 1–10 секунд.
- Выключение закрывает сокет. `lv:false` не посылается: некоторые версии WLED могут
  этим отключить Peek другого клиента. Команды изменения света не отправляются.
- Стандартный поток WLED может быть сжат самой прошивкой для длинных лент; виджет
  отображает не чаще 12.5 кадров/с, до 160 образцов на полосу. `/json/live` не опрашивается.
- Peek показывает только принятые кадры реального устройства; демонстрационных кадров нет.

## Реализация

В Node preview: один upstream WebSocket на устройство, общий для подписчиков;
SSE `/api/devices/:id/peek` доставляет кадры фронтенду. Адреса только из локального
реестра, Origin/Sec-Fetch-Site проверяются. Закрытие последней подписки закрывает WS.
Фронтенд объединяет одинаковые источники двух краёв в одну подписку и освобождает
их при выключении, смене ламп, скрытии и размонтировании.

В Tauri добавлен исходник отдельного WS-транспорта с IPC Channel и командами
start_peek/stop_peek. Нативная сборка пока **не компилировалась и не проверена**:
на компьютере по-прежнему нет Rust/MSVC/Windows SDK. Проверенный путь — Node preview.
Для Tauri необходим отдельный build/test и Cargo.lock перед выпуском.

## Проверки

`pnpm run check` проверяет декодер, разделение подписок, read-only запрос,
освобождение ресурсов, потерю кадров и переподключение. `tests/integration/peek-smoke.mjs`
использует два локальных HTTP+WS контроллера и настоящий браузер Edge. Проверены
кадры на canvas, изменение цветов, разные источники, один общий сокет для двух
одинаковых источников, потеря/возврат кадров, остановка и отсутствие команд изменения
света. Реальные лампы владельца в эти проверки не включались.

## Запуск после обновления прототипа

Веб-интерфейс WLED открывать и нажимать в нём Peek не требуется: виджет сам посылает
`{"lv":true}`. Ошибка «лампа недоступна» может также означать, что локальный сервер
старой версии ещё работает и не знает маршрут Peek. Launcher сравнивает отпечаток
backend-исходников с `/api/health` и перезапускает устаревший сервер. Перед остановкой
он проверяет loopback-порт, точный исполняемый файл Node и абсолютный путь скрипта
этого проекта. Чужой процесс не останавливается.

Проверка на двух физических WLED-контроллерах прошла: автоматический запрос потока
работает без ручного включения веб-Peek. Адреса и локальные снимки проверки не входят
в опубликованные исходники. Нативная Windows-сборка по-прежнему не проверялась.

## Переключатель в настройках

Peek включён по умолчанию. Переключатель находится только в настройках виджета;
на главной панели кнопки Peek нет. Отключение сохраняется локально и действует
при следующем запуске. Включение также запоминается. Мини-режим и скрытие окна
приостанавливают поток, сохраняя выбор пользователя; возврат возобновляет поток,
если Peek включён. Настройка не включает и не выключает сами лампы.
Закрепление «Поверх других окон» доступно только через контекстное меню ПКМ.
`n## Плавная прозрачность — вариант 02`nЯркость пикселя задаёт его прозрачность: alpha = max(R,G,B)/255. Чёрный пиксель имеет нулевую альфу. Перед кадром canvas очищается; при выключении лампы, отсутствии или устаревании кадров полоса прозрачна. Фон и тень у полос отсутствуют. Сглаживание позволяет плавно отображать переходы между соседними пикселями.
