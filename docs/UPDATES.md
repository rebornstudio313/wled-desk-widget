# О программе и обновления

В конце настроек есть версия, идентификатор сборки, проверка обновлений и ссылка на GitHub Release. Проверка выполняется только по нажатию, без отправки адресов ламп, настроек или токенов. Приложение не скачивает и не устанавливает обновления автоматически.

Используется публичный список последних 100 GitHub Releases проекта rebornstudio313/wled-desk-widget. Черновики и неопубликованные теги игнорируются. Предварительные версии получают предварительные и стабильные обновления; стабильные — только стабильные. Версии сравниваются по SemVer: alpha.10 новее alpha.2. Метаданные после + не определяют порядок версий.

Результаты: доступно обновление, новых обновлений нет, выпусков пока нет, ошибка соединения или ограничение запросов GitHub. Ошибка сети не выдаётся за актуальную версию. Ссылки открывают только страницу Releases этого проекта в браузере пользователя.

## Номера версий и сборок

Версия продукта: 0.1.0-alpha.3. package.json, Cargo.toml и tauri.conf.json должны содержать одинаковую версию. scripts/prepare-build.mjs проверяет совпадение и формирует уникальный идентификатор из времени UTC и SHA-256 исходников и конфигурации. Он запускается при pnpm build, pnpm build:native и pnpm dev. Интерфейс и нативный EXE используют общие метаданные сборки; копия находится в release-local/build-info.json.

Для публикации обновления нужно увеличить версию продукта в трёх файлах, обновить Cargo.lock и создать опубликованный GitHub Release с соответствующим тегом. Простое пересоздание EXE меняет идентификатор сборки, но не считается новой версией для пользователей. Установщик и архив исходников именуются по версии автоматически.

Источники: [GitHub Releases API](https://docs.github.com/en/rest/releases/releases#list-releases), [SemVer](https://semver.org/).
