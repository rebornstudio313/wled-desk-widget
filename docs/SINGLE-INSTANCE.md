# Один экземпляр приложения

Windows-версия использует tauri-plugin-single-instance, зарегистрированный первым плагином до загрузки профиля и запуска соединений. Блокировка привязана к постоянному идентификатору io.wleddesk.app, без добавления версии приложения.

Повторный запуск завершает вторую копию и показывает окно первого процесса. Если виджет скрыт в трее или свёрнут, он восстанавливается; положение проверяется относительно доступных экранов. Дополнительные аргументы запуска не выполняются. Повторный запуск не создаёт второй набор Peek-потоков, горячих клавиш или обработчиков файлов профиля. При завершении процесса системная блокировка освобождается.

Проверка tests/integration/single-instance-smoke.ps1 запускает собранный EXE, проверяет сохранение первого процесса, повторное открытие из трея, восстановление свёрнутого окна и несколько одновременных повторных запусков. Проверяется настольный EXE; сервер браузерного preview имеет отдельный жизненный цикл.

Защита действует между версиями, в которых она уже установлена. Старые EXE без этой функции не участвуют в блокировке; закройте старую версию перед первым запуском новой. Разные учётные записи Windows и запуск с разными правами требуют отдельной проверки; основная поддерживаемая установка — для текущего пользователя без прав администратора.

Источник: [Tauri Single Instance](https://v2.tauri.app/plugin/single-instance/).
