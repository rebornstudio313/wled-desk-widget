# Автозагрузка Windows

В настройках после прозрачности есть переключатель «Запускать вместе с Windows». По умолчанию выключен. Настройка относится к текущей учётной записи (HKCU\Software\Microsoft\Windows\CurrentVersion\Run, значение WLED Desk Widget), без прав администратора. Запуск происходит при входе в Windows, а не до входа пользователя.

Дополнительная настройка «При автозапуске скрывать в трей» действует только на запуск с аргументом --autostart. Обычный запуск ярлыком показывает окно; повторный запуск показывает существующий экземпляр. Настройки ламп и положение окна сохраняются. Во время отсутствия Wi-Fi действует штатное переподключение.

Включение использует текущий EXE с кавычками в пути и аргументом --autostart. Для постоянного использования сначала установите приложение и включите переключатель в установленной версии. Если переносите portable EXE, выключите и включите автозагрузку после переноса. Установщик обновляет существующую запись при обновлении, но не включает её без выбора пользователя. Удаление приложения убирает запись автозагрузки. Пользовательские данные намеренно не удаляются.

Проверка записи и удаления значения выполнена отдельным тестом с уникальным тестовым именем; запись пользователя не меняется во время этого теста. Реальная перезагрузка Windows для проверки не выполнялась.
