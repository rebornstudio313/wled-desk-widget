# Отрисовка и перемещение окна

Нативный Acrylic отключён: на проверенной Windows он добавлял прямоугольную подложку и тормозил перемещение. Внешний вид создаёт прозрачный WebView с CSS-фоном. CSS backdrop-filter в настольной оболочке отключён, поскольку не обеспечивает настоящее размытие рабочего стола и увеличивает стоимость перерисовки. Скругления ограничены CSS clip-path и нативным SetWindowRgn (без Acrylic), нативные тень и изменение размера отключены.

Дополнительно убираются WS_CAPTION и WS_THICKFRAME при создании, фокусировке, изменении размера и восстановлении из трея: системная оболочка может вернуть их при показе окна. Другие флаги и нативное перетаскивание сохраняются.

На событиях перемещения больше не выполняются чтение координат/мониторов и запись файла. После 350 мс без новых событий координаты снимаются один раз, запись выполняется вне UI-потока. Закрытие в трей сохраняет последнюю позицию немедленно. Автоматическая коррекция по рабочей области не выполняется на каждом изменении размера; она остаётся при восстановлении и смене DPI.

Проверки: tests/integration/window-motion-smoke.ps1 проверяет отсутствие заголовка/рамки, серию перемещений и запись последней позиции. Браузерные проверки покрывают полный/мини-режим, настройки прозрачности, контекстное меню и отдельное питание ламп. Программная скорость перемещения не заменяет оценку плавности реального захвата мышью на конкретном компьютере.
