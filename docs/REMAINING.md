# Оставшиеся работы

Текущая версия: 0.1.0-alpha.3. Реализованы автопоиск и ручные адреса, актуальное состояние, отдельное питание, палитры с образцами, сцены, наборы копирования, Peek, мини-режим, трей, сохранение позиции, пользовательские глобальные клавиши, прозрачность с предпросмотром, проверка выпусков, один экземпляр и отключаемая автозагрузка.

Перед стабильным выпуском: чистая Windows 10/11, обновление и удаление установленного приложения, реальная проверка входа Windows/автозагрузки и разных DPI/мониторов, проверка аппаратных контроллеров и полного набора лицензий. Установщик пока unsigned.

Дальше: экспорт/импорт профиля, восстановление повреждённых файлов, изменение IP без удаления устройства, поиск/избранное эффектов, отдельное окно Peek. RGBW/CCT, сегменты, плейлисты и расширенный редактор сценариев — отдельные этапы. Аппаратная покадровая синхронизация и интеграции со сторонним RGB-ПО не заявлены.
