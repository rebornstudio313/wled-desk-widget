# Что осталось после компактного прототипа

## Уже проверено

320 CSS px ширина основной панели, высота менее 450 CSS px в стандартном состоянии.
Настройки открываются поверх панели, не расширяют основной виджет. Убраны большие
страничные шапка/подвал/боковая колонка. Цвета и SVG-иконки приближены к выбранному
стеклянному макету. Нативный фон подготовлен как прозрачный; это не проверка DWM blur.
Сборка, TypeScript, 7 сетевых тестов и UI smoke с проверкой размеров пройдены.

## 1. Настоящее настольное окно — ближайший приоритет

- Установить Rust/MSVC/Windows SDK и проверить фактическую сборку Tauri.
- Исправить обнаруженные native build ошибки; закрепить Cargo.lock и CLI.
- Проверить прозрачное безрамочное окно на Windows, нативный blur/acrylic и fallback.
  CSS backdrop-filter не гарантирует размытие рабочего стола через WebView2.
- Перетаскивание, закрытие/сворачивание, поверх окон, положение и несколько мониторов.
- Трей и отсутствие зависимости от браузерного app-mode/локального Node preview.
- Проверить размер на 100/125/150/200% DPI, клавиатурный фокус и доступность.

## 2. Надёжное состояние

- Полный профиль вместо одного списка устройств; миграции, атомарное сохранение и backup.
- Сохранение предпочтений пользователя, режима работы, избранных цветов и быстрых слотов.
- Непрерывная подписка WebSocket с polling fallback, конфликт локального редактирования
  и внешнего обновления; отмена устаревших запросов и сохранение финальной команды.
- Переименование ламп, изменение адреса, восстановление после DHCP и обрывов сети.

## 3. Пользовательские группы и сцены

- Группы с именами и произвольным составом; смешанное состояние цвета/питания/эффекта.
- Расширение реализованного редактора «Работа», «Вечер», «Кино»: палитры, сегменты и расширенные каналы.
- Сцена задаёт отдельный presetId или состояние для каждого участника; независимые ошибки.
- Импорт/экспорт сцен с сопоставлением устройств.

## 4. Полные возможности освещения

- Палитры и метаданные эффектов, корректные дополнительные параметры.
- Создание/переименование/перезапись/удаление пресетов с backup и проверкой API версии.
- Плейлисты, выбор сегментов, переходы; поддержка RGBW/CCT только при capability.
- Избранное и поиск; расширенные настройки редактора быстрых слотов.

## 5. Настройки, совместимость и релиз

- Интерфейс общих настроек, резервные копии, справка и родной веб-интерфейс WLED.
- mDNS после ручного подключения; расширенные настройки контроллера отдельным этапом.
- Матрица реальных прошивок и устройств; профиль ошибок сети и offline-групп.
- Английская локализация, собственные иконки/branding, финальная визуальная сверка.
- Подписанный либо явно неподписанный установщик, проверка чистой Windows и обновления.
- GitHub README, screenshots, licences, воспроизводимые сборки и проверенный release.

Интеграции с другими RGB-программами исключены. Настройка нынешних ламп владельца
и работа периферии не изменяются ради разработки виджета.
