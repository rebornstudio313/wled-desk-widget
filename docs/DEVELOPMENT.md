# Запуск прототипа 0.1

Требуется Node.js 24+ и pnpm 11.25.0. Из корня проекта:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://127.0.0.1:1420. При сохранённых адресах автоматически включается live; при пустом реестре — симулятор двух ламп. «Мои лампы» -> адрес -> «Добавить лампу» проверяет WLED и сохраняет
устройство. В preview список хранится в `.local/preview-devices.json` (Git ignore).
Адреса не включены в исходники; читается только локальный реестр пользователя.

```sh
pnpm check
pnpm build
pnpm preview
```

После build preview доступен на http://127.0.0.1:1421. Сервер слушает только loopback.
Live HTTP работает через backend, а не напрямую из браузера. Важно: это прототип
для разработки, не публичный сетевой сервер и не упакованный desktop installer.

## Что работает в прототипе

Демо, выбранный визуальный стиль, добавление/сохранение/удаление адресов,
чтение состояния, питание, RGB/HEX, яркость, выбор эффекта по имени для каждой лампы,
скорость/интенсивность, выбор всех/одной лампы, чтение и применение пресетов одной лампы,
проверка адресов и patch, сериализация записей и частичные ошибки.

Изменения ползунков отправляются после отпускания или клавиатурного изменения,
а не на каждый пиксель движения. Состояние обновляется опросом раз в 5 секунд;
WebSocket/coalescing в фоне — следующий этап. Если лампа сообщает live/realtime,
виджет только отображает статус и не управляет источником потока.

## Пока не реализовано

Группы с собственными именами, запись/редактирование пресетов, пользовательские быстрые
расширенные сценарии (палитры/сегменты), палитры и метаданные, tray, автообнаружение,
полный профиль/миграции, полноценный simulator HTTP, Windows installer, автозапуск.
Дополнительные параметры эффектов пока общие, отключены для Solid; метаданные появятся позже.

## Нативная сборка

Tauri CLI не включён в зависимости preview: установить его отдельно при подготовке native build.
Tauri/Rust исходники присутствуют; нативная сборка не проверена из-за отсутствия Rust,
MSVC C++ Build Tools и Windows SDK. Пререквизиты:
https://v2.tauri.app/start/prerequisites/ . Подготовлены команды IPC и отдельное
хранилище в app-data; нет интеграций с другими RGB-программами.

## Браузерный smoke

`PLAYWRIGHT_MODULE` может указывать на установленный Playwright ESM entrypoint.
Затем `node tests/integration/ui-smoke.mjs` (нужен Edge). Тест запускает localhost
сервер и фиктивную лампу, профиль находится во временной папке и удаляется после теста.
Обычный `pnpm check` не требует браузера. Скриншоты сохраняются в docs/screenshots.

## Восстановление ламп при запуске

Начальное состояние UI — загрузка. Сначала читается сохранённый реестр. Если он
не пуст, автоматически включается live и читается состояние каждой лампы; до
ответа лампы остаются видимыми, после ошибки отмечаются offline. Если реестр пуст,
открывается demo. При ошибке чтения реестра используется live с сообщением об ошибке
и повторным чтением; demo не подменяет отсутствующее соединение. При следующем
запуске сохранённые устройства снова имеют приоритет над временно выбранным demo.
Никакие команды включения, цвета или эффектов при загрузке не отправляются.

`tests/integration/ui-smoke.mjs` проверяет перезагрузку после добавления лампы,
автоматическое восстановление без открытия настроек и запуск с offline-устройством.
