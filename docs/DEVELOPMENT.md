# Разработка WLED Desk | Widget

Требуется Node.js 24 и pnpm 11.25.0. Из корня: `pnpm install --frozen-lockfile`,
затем `pnpm dev`. Сервер разработки открывается на http://127.0.0.1:1420.
Собранный браузерный интерфейс: `pnpm build`, `pnpm preview`, http://127.0.0.1:1421.
Сервер preview слушает только loopback; обращения к WLED выполняет backend.

## Устройства и запуск

Приложение работает только с реальными добавленными WLED. Демонстрационного режима
и автоматических виртуальных ламп нет. Пустой реестр открывает добавление первой
лампы. Сохранённые адреса загружаются автоматически; недоступные лампы сохраняются
в списке с ошибкой связи. Запуск только читает состояние и не меняет свет.

В нижней строке отображаются выбранные лампы и значки: зелёный — подсветка включена,
серый — выключена / выполняется подключение, оранжевый — нет связи. Наведение
показывает точное состояние и адрес. При одинаковых именах добавляется суффикс адреса.

Preview хранит реестр в `.local/preview-devices.json`, сценарии в `.local/scenes.json`.
Нативная сборка использует каталог данных `io.wleddesk.app`; профили раздельные.
Личные адреса не входят в Git и исходный архив.

## Проверки

`pnpm check` запускает модульные проверки и TypeScript; `pnpm build` собирает UI.
Для browser tests нужен Playwright и Edge. Переменная `PLAYWRIGHT_MODULE` может
содержать ESM-путь к Playwright. Запустите `pnpm test:ui`, `pnpm test:peek`,
`pnpm test:scenes`, `pnpm test:compact`. Каждый тест поднимает локальные HTTP/WS
имитаторы WLED и временный профиль; это не режим приложения для пользователя.

Проверяются: пустой профиль, добавление/удаление и восстановление устройств,
состояния включена/выключена/offline, цветовое кольцо, HEX, эффекты, сохранение
сценариев без изменения света, частичные ошибки, Peek и мини-режим.

## Нативная сборка

`pnpm build:native` требует Rust MSVC, C++ Build Tools, Windows SDK и WebView2.
См. [BUILD-WINDOWS.md](BUILD-WINDOWS.md), [BUILD-STATUS.md](BUILD-STATUS.md).
Кнопки трея и закрепления поверх окон работают в Tauri; в браузере они отключены.
Подробности: [WINDOW-MODES.md](WINDOW-MODES.md), [SCENES.md](SCENES.md), [PEEK.md](PEEK.md).

Потоковые состояния и резервный опрос: [REALTIME.md](REALTIME.md).
