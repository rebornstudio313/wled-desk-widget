# Работа, Вечер, Кино — пользовательские сценарии

На каждой карточке появилась маленькая шестерёнка. Она открывает редактор.
Первое нажатие ещё не настроенной карточки также открывает редактор. Выберите
участвующие лампы галочками и настройте действие отдельно для каждой:

- **Пресет WLED:** каталог читается с этой конкретной лампы, показываются имя и номер.
- **Свои параметры:** питание, RGB/HEX, яркость, эффект, скорость и интенсивность.
  Кнопка «Взять текущее состояние» копирует эти поддерживаемые поля с лампы.

«Сохранить» записывает сценарий в профиль виджета, не меняя освещение. Нажатие
карточки применяет сохранённые действия. Состав сценария не зависит от текущего
выбора «Все лампы» / отдельной лампы. Возможна комбинация: собственные параметры
для первой лампы, пресет с другим номером для второй. Номер пресета не копируется
на все устройства. Эффект хранится по имени и разрешается в ID отдельно для каждой
прошивки. Отсутствующий эффект или пресет сообщается как ошибка конкретной лампы.

Если одна лампа недоступна, остальные получают своё действие. Частичные ошибки
показываются в статусе; сохранённые назначения не удаляются. Удалённую из реестра
лампу нужно снять галочкой при редактировании. Каталоги offline-устройства недоступны;
сохранённое назначение остаётся в профиле. Отмена и закрытие редактора не сохраняют.

В приложении нет демонстрационного режима. В рабочем
режиме сценарии сохраняются через локальный backend в `.local/scenes.json`, рядом
с реестром устройств; запись атомарная, предыдущая версия хранится в `.bak`.
Файлы игнорируются Git. При использовании WIDGET_PROFILE_FILE сценарии находятся
в том же каталоге, что и этот профиль. Версия файла — 1. До 64 назначений на слот.

Свои параметры пока относятся к первому сегменту и трём RGB-каналам. Расширенные
сегменты, палитры, RGBW/CCT и переходы остаются будущими возможностями редактора.
Пресет WLED используется как есть и может содержать собственные расширенные настройки.

В Rust добавлены исходники list_scenes/save_scene для app-data. Они требуют будущей
нативной компиляции и проверки. Проверенный путь сейчас — Node preview.

Проверки: 12 unit tests; `tests/integration/scenes-smoke.mjs` проверяет смешанные
назначения, отсутствие команд света при сохранении, восстановление после перезапуска
backend, разные ID одного эффекта на двух устройствах, частичные ошибки, отмену и
валидацию. Дополнительно пройдены обычный UI smoke и Peek smoke. Все команды света
при проверках сценариев направлялись только локальным тестовым контроллерам.

## Объединение ламп после пресета

Выберите одну лампу, примените её пресет и нажмите «Все лампы». Виджет заново
читает состояние выбранной лампы и передаёт остальным включение, яркость, RGB,
эффект по названию, скорость и интенсивность первого сегмента. Номер пресета
не копируется, сохранённые пресеты и схема ленты не изменяются. Операция работает
в обе стороны. При недоступном эффекте или лампе показывается ошибка для цели;
при недоступном источнике объединение не выполняется. Повторное нажатие уже
выбранной группы ничего не переписывает. Запуск приложения не копирует свет.

Пока переносится первый сегмент и основной RGB-цвет. Многосегментные пресеты,
палитры и RGBW/CCT требуют расширения протокола переноса.
`n## Выбор получателей для отдельной лампы`nВыберите лампу в верхнем списке и нажмите «Синхронизировать с…». Отметьте любое число других добавленных ламп. «Сохранить выбор» сохраняет только получателей; «Синхронизировать сейчас» сохраняет выбор и однократно копирует текущее состояние источника. У каждой исходной лампы свой независимый список. В общих настройках возле каждой лампы также доступен значок связи.`n`nСписки хранятся в sync-targets.json рядом с профилем устройств, с резервной копией .bak. Настройки не создают постоянную связь, не копируют пресеты по номеру и не распространяют изменения с телефона автоматически. Ошибка недоступной цели показывается в окне; остальные выбранные цели могут получить свет. При недоступном источнике команды не отправляются. Переносятся питание, яркость, RGB и параметры эффекта первого сегмента, без схемы ленты и многосегментного пресета целиком.
