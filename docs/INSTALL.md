# Установка WLED Desk | Widget

## Windows-сборка

Перед скачиванием проверьте [статус сборки](BUILD-STATUS.md). Подготовленный EXE
нельзя считать проверенным стабильным релизом до нативной проверки и установки.
Установщик публикуется в Releases; файл с суффиксом `-setup.exe` — установщик,
`wled-desk-widget.exe` — исполняемый файл приложения. SHA256SUMS.txt содержит контрольные суммы.
Сборка без цифровой подписи может вызывать предупреждение Windows.

Установка рассчитана на текущего пользователя. Для интерфейса нужен WebView2;
при его отсутствии установщик должен скачать официальный runtime Microsoft.
После запуска откройте настройки, укажите свои локальные адреса WLED и добавьте лампы.
Далее сохранённые устройства подключаются автоматически. Ошибка одной лампы не
удаляет её адрес. Мини-режим включается в верхней строке, сценарии — шестерёнками на карточках.

## Без установщика

Установите Node.js 24 и pnpm 11.25.0, откройте терминал в каталоге проекта:

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm preview
```

Откройте `http://127.0.0.1:1421`. Это браузерный прототип: скрытие в системный
трей и изменение размера настоящего окна доступны только нативной версии.

## Данные

Preview: `.local/preview-devices.json`, `.local/scenes.json`; старые файлы сценариев
сохраняются в `.bak`. Native: каталог данных приложения `io.wleddesk.app`.
Preview и native используют раздельные профили; адреса preview не мигрируют автоматически.
Не отправляйте свои конфигурации Wi-Fi и резервные копии WLED в публичные issues.
