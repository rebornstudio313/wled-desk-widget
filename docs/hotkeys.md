# Горячие клавиши

В Windows работают даже из трея. В настройках есть список и общий выключатель; выбор сохраняется после перезапуска. Команды света действуют на текущий выбор ламп. Команды, занятые другой программой, отмечаются в настройках; остальные продолжают работать.

Стандартные сочетания используют Ctrl + Alt + Shift:

| Клавиша | Действие |
|---|---|
| W | Показать виджет / скрыть в трей |
| P | Включить / выключить выбранные лампы |
| ↑ / ↓ | Яркость ±5%, границы 0–100%; 0% выключает свет |
| M | Мини / полный виджет |
| S | Настройки |
| 1 / 2 / 3 | Сценарий Работа / Вечер / Кино |

Ненастроенный сценарий открывает его редактор. При открытом диалоге сценарии не переключаются. Во время выполнения команды повторные команды света пропускаются. Удержание сочетания не вызывает автоповтор. Сочетания привязаны к физическим клавишам и работают в русской и английской раскладках. Для каждого действия можно добавить любое количество альтернативных назначений: нажмите «Добавить сочетание», нажмите клавиши и подтвердите кнопкой «Добавить». Поддерживаются одиночные клавиши и сочетания с Ctrl, Alt, Shift, Win. Одиночная глобальная клавиша будет занята виджетом и в других приложениях. Во время записи текущие сочетания временно отключены. Escape отменяет запись. Кнопка × удаляет назначение; можно оставить действие без сочетаний. Повторы одного сочетания между действиями запрещены; сочетания, занятые системой или другими приложениями, отмечаются отдельно. Назначения сохраняются после перезапуска. Можно вернуть стандартный набор. Изменение выполняется сразу после подтверждения добавления или удаления; отдельной кнопки сохранения нет.

В браузерной версии сочетания доступны при фокусе окна; скрытие в трей доступно только в Windows-приложении.

Глобальные сочетания используют стандартный Windows RegisterHotKey с MOD_NOREPEAT, без перехвата обычного ввода: [документация Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey).
