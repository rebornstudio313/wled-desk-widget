# Статус сборки WLED Desk | Widget

Версия: **0.1.0-alpha.1**, Windows x64. Нативный EXE и NSIS setup.exe успешно собраны.

- Rust 1.99.1 MSVC, Microsoft C++ Build Tools 2026, Windows SDK 10.0.26100.
- Приложение запущено на Windows 10 22H2; WebView2 загрузил интерфейс и IPC.
- Добавлены перетаскивание верхней строки, булавка «Поверх окон», трей и автоматический размер окна.
- Отключён прямоугольный нативный слой ручного растягивания, убраны внешние отступы и тень окна; мини-режим использует маленькое цветовое кольцо.
- 12 unit tests и UI / Peek / Scenes / Compact browser tests прошли.
- Сквозная проверка установки на чистой Windows, DPI и нативных устройств ещё не завершена.
- Цифровой подписи нет. Это экспериментальная alpha, не стабильный релиз.

Локальные артефакты в release-local (каталог не публикуется как исходный код):

- `WLED Desk Widget_0.1.0-alpha.1_x64-setup.exe` — установщик.
- `wled-desk-widget.exe` — исполняемый файл.
- `SHA256SUMS.txt` — контрольные суммы бинарников.
- `wled-desk-widget-0.1.0-alpha.1-source.zip` — исходники без личных данных.

Результаты UI-автоматизации не подтверждают физический цвет ламп и не заменяют проверку
установки на чистой системе. Инвентарь лицензий содержит пункты needsReview, требующие
дополнительной проверки перед стабильным бинарным релизом.
