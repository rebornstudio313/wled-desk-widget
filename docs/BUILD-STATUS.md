# Статус сборки

Версия: **0.1.0-alpha.3**, Windows x64. EXE и NSIS installer собираются локально. Установщик не подписан. Это alpha.

Выполненные проверки перечисляются в release-local/QA-RESULTS.txt для конкретной сборки. Текущий набор включает модульные тесты Node, нативные тесты Rust и регрессионные браузерные проверки на изолированных лампах. Нативные сценарии проверяют рамку/скругление, один экземпляр, восстановление из трея и движение окна. Автозагрузка имеет тест записи и удаления отдельного тестового значения HKCU, без изменения пользовательской записи.

Нужна отдельная проверка установки, обновления и удаления на чистой Windows 10/11, реального запуска после входа в Windows и разных физических DPI/мониторов. Браузерные тесты не подтверждают физическое свечение реальной ленты. Инвентарь сторонних лицензий содержит пункты для ручной проверки; это не заявление о готовности стабильного релиза.

Артефакты: release-local/wled-desk-widget-0.1.0-alpha.3-x64-setup.exe, wled-desk-widget.exe, архив исходников, build-info.json и SHA256SUMS.txt. Личные данные и .local не входят в исходники.
