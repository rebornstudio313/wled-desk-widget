# План проверок

## Автоматические проверки будущего приложения

- Нормализация IP/hostname/URL; отклонение неподдерживаемых схем, credentials и дублей.
- Парсинг разных ответов WLED; отсутствующие поля, неизвестные поля, повреждённый JSON.
- RGB/HEX, яркость, сегментные patch без изменения физической топологии.
- Сопоставление одинакового имени эффекта с разными ID и обработка неоднозначности.
- Пресеты с разными ID/именами, локальная сцена со ссылкой на удалённое устройство.
- Coalescing ползунков, окончательное значение, таймауты, backoff, отмена,
  отключение во время записи, отсутствие устаревшего replay после подключения.
- Групповой частичный успех, смешанные значения, отсутствие одной capability.
- Хранилище: schemaVersion, миграции, аварийная запись, резервное восстановление.
- Экспорт диагностики без паролей/полных конфигураций и персональных сетевых данных.

## Интеграционные проверки

Simulator должен воспроизводить HTTP+WS, задержки, разрывы, разные каталоги,
пресеты и realtime-статус. В CI железо не требуется.
Отдельно — 10 симулируемых ламп без неконтролируемого роста соединений/очередей.

## Реальные лампы и UI

ESP8266/ESP32, неравное число LED, RGB и RGBW при наличии оборудования;
целевые версии прошивок проверяются и записываются в таблицу совместимости.
Сравнить цвет/яркость с родным UI WLED, изменения с телефона, перезапуск приложения,
роутера/лампы, потерю Wi-Fi, изменение DHCP адреса.

Проверить 100/125/150/200% DPI, несколько мониторов, сворачивание, трей,
фокус клавиатуры, экранный диктор и отсутствие интернета.

## Готовность релиза

Чистая Windows без Node/Rust/IDE; установка, WebView2 prerequisite, первый запуск,
добавление лампы, обновление с сохранением профиля, корректное удаление приложения.
Не заявлять «проверено» для невыполненных сценариев. Результаты — в release notes.
