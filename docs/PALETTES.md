# Цвет эффекта и палитры

В основном и мини-виджете эффект и цвет расположены в одной строке; скорость и интенсивность — ниже. «Цвет» загружает названия палитр из /json/pal каждой лампы, образцы — из страниц /json/palx. Цветная полоска показана в каждом пункте списка и на выбранной кнопке. Color 1 и сочетания основных цветов используют текущее состояние сегмента; Random Cycle имеет условный цветовой образец, а не симуляцию случайного эффекта. Предпросмотр палитры не заменяет Peek.

Палитра меняется отдельным seg.pal без сброса эффекта или геометрии ленты. Для всех ламп доступны общие названия; номер палитры определяется отдельно на каждой лампе. Изменения с телефона обновляют выбор и основные цвета образца. Источником служит первый сегмент, как у остальных основных регуляторов. Если лампа не отдаёт каталог/образец, несуществующие цвета не выдумываются. Пользовательские палитры вне каталога имён пока отображаются своим номером.

Образцы загружаются один раз для выбранной лампы за сеанс, а не при каждом опросе состояния. Каталоги обновляются регулярным чтением состояния приложения. Базовые палитры доступны независимо от поддержки образцов.

Источник: [WLED JSON API — Palettes](https://kno.wled.ge/interfaces/json-api/#palettes).
