# Подготовка GitHub и распространение

## Репозиторий

Имя репозитория: wled-desk-widget. Публичный репозиторий пока не создан.
README на русском и английском, MIT для нового кода, CONTRIBUTING, SECURITY,
CHANGELOG, issue/PR templates, изображения интерфейса, таблица совместимости.
Никаких пользовательских IP, Wi-Fi паролей, полных WLED backups, подписывающих
ключей и приватных журналов в исходниках и артефактах.

## CI

Подготовительный workflow сейчас проверяет JSON и обезличенный пример профиля.
При появлении приложения добавить TypeScript typecheck, lint, доменные тесты,
Rust fmt/clippy/tests, simulator integration и Windows build. Для PR — без секретов.
Публикацию бинарников не запускать из недоверенного PR.

## Сборки

После создания Tauri-проекта зафиксировать зависимости и инструменты lock-файлами.
Первый бинарный формат — Windows x64 NSIS installer (.exe). Portable-вариант
предлагать только после проверки self-contained поведения и WebView2.
macOS/Linux — последующий самостоятельный этап; не объявлять поддержанными заранее.

## Первый релиз

1. Закрыть критерии MVP и совместимости, обновить версии и CHANGELOG.
2. Собрать в чистом CI, проверить установку и сохранение данных при обновлении.
3. Подготовить SHA-256 сумм, release notes и список известных ограничений.
4. Подписание Windows требует отдельного сертификата; без него честно описать
   отсутствие подписи и возможные системные предупреждения. Не советовать отключать защиту.
5. Публиковать tagged release после просмотра готовых артефактов.

Для обычного пользователя: скачать установщик из Releases, установить,
добавить адрес WLED. Node, Rust и права администратора для работы виджета не нужны.
Автообновление не включать до настройки подписанных обновлений и ключей в CI.

Актуальные шаги: [PUBLISH-GITHUB.md](PUBLISH-GITHUB.md), [BUILD-WINDOWS.md](BUILD-WINDOWS.md), [BUILD-STATUS.md](BUILD-STATUS.md).
