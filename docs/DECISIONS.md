# Решения и статус

| Решение | Статус |
|---|---|
| Имя Widget LED RGB, отдельная папка на рабочем столе | задано пользователем |
| Основа UI — стеклянный вариант 03 с вкладками | выбрано пользователем |
| Только WLED, без какой-либо интеграции с SignalRGB | явно задано пользователем |
| Ручной ввод адресов, группы, эффекты, пресеты, настройки | задано пользователем |
| Публичное распространение через GitHub в будущем | задано пользователем |
| Tauri 2 + Rust + React/TypeScript | предлагаемое техническое решение |
| Windows первой; локальный профиль, без облака | базовый план реализации |
| MIT для нового кода | начальная лицензия проекта, можно изменить до публикации |
| Группы не копируют физические параметры разных лент | архитектурное ограничение |
| Полные системные настройки доступны через родной UI WLED | граница первого релиза |

## Ещё определить при реализации

- Реальный минимальный размер виджета и поведение раскрытия на разных DPI.
- Итоговые поддерживаемые версии WLED по результатам тестов.
- HTTPS и авторизация для нестандартных устройств; секреты не хранить в открытом профиле.
- Схема advanced backup и список безопасно переносимых полей конфигурации.
- Сертификат подписи, владелец/URL GitHub, релизные ключи и идентификатор приложения.

Никаких текущих индивидуальных адресов владельца в публичных примерах.
Существующие настройки ламп, сторонних приложений и клавиатуры не изменялись
при подготовке этого проекта.
