# План разработки

Есть ранний React/Node-прототип; проверенный объём — в STAGE1-RESULT.md.
Этап 1 частично выполнен, отдельные базовые функции этапов 2–4 доступны.
Нативная оболочка и остальные критерии ниже ещё не закрыты.

| Этап | Работа | Критерий готовности |
|---|---|---|
| 0 — спецификация | документы, границы, типы, структура, референс | создано в текущей подготовке |
| 1 — фундамент | Tauri/React, зависимости, lock-файлы, shell, simulator, CI | окно запускается, demo работает без сети |
| 2 — подключение | адрес, проверка WLED, UUID, дубли, сохранение и переподключение | после перезапуска лампы восстановлены без ручного ввода |
| 3 — цвет | выбранный макет, питание, RGB/HEX, яркость, сегменты, очередь команд | одна и две реальные лампы управляются без перегрузки |
| 4 — каталоги | эффекты, метаданные, палитры, поиск, кеш | каждая лампа показывает свой реальный каталог |
| 5 — группы | состав, смешанные значения, общий patch, совместимость эффектов | группа с одной офлайн-лампой выдаёт частичный результат |
| 6 — пресеты | чтение/применение/сохранение, локальные сцены, быстрые слоты | сцена применяет разные presetId на разных лампах |
| 7 — desktop | трей, положение, DPI, несколько мониторов, настройки UI | удобное ежедневное использование без IDE |
| 8 — расширенное | импорт/экспорт, резервные копии, плейлисты, mDNS, UDP Sync opt-in | совместимость и откат проверены, нет скрытых изменений |
| 9 — релиз | документация пользователя, сборка, QA, лицензии, GitHub Releases | установка на чистую Windows и сценарий первого запуска пройдены |

## Минимальная пригодная версия 0.1

Этапы 1–7 в сокращённом объёме: ручные адреса, устойчивое хранение, базовое
управление, каталоги эффектов/палитр, простые группы, чтение/применение пресетов,
три локальные сцены, трей. Без собственного редактора системной конфигурации,
автообновления, сложного редактора плейлистов и точной фазовой синхронизации.

## Публичная версия 1.0

Проверенные резервные копии и импорт, завершённый UX ошибок, совместимость
прошивок, английская локализация, документация и установщик; расширения этапа 8
можно выпускать по отдельности с честной таблицей возможностей.
