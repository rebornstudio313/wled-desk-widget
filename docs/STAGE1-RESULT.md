# Результат первого этапа

## Реализовано и проверено локально

- React/TypeScript + Vite: стеклянный интерфейс по выбранному макету, адаптивная ширина.
- Демо двух устройств, независимые состояния, общие команды и выбор одной лампы.
- Подключение WLED по адресу через localhost backend, сохранение/удаление устройств.
- Питание, RGB/HEX, яркость, каталог эффектов, скорость/интенсивность, чтение и запуск пресетов.
- В группе эффект разрешается по имени отдельно для каждой лампы.
- Проверка LAN-адресов, ограничение полей команд, таймауты и последовательные записи.
- Backend preview привязан к 127.0.0.1; записи из чужого Origin отклоняются.
- Запуск через Start Widget.cmd: отдельное окно Edge app-mode либо браузер.

## Выполненные проверки

TypeScript --noEmit и production build прошли. 7 Node-тестов адаптера прошли.
Браузерный smoke прошёл: demo, ширина 390px без горизонтального переполнения,
добавление HTTP simulator, сохранение, питание, RGB, эффект, запрет чужого Origin,
удаление. Реальные лампы автоматически не добавлялись и не изменялись.

Скриншоты: [обычная компоновка](screenshots/prototype-demo.png),
[узкая компоновка](screenshots/prototype-compact.png).

## Честные ограничения

Это **браузерный desktop preview**, не готовый нативный .exe и не установщик.
Исходники Tauri/Rust backend добавлены, но не компилировались: на компьютере нет
Rust/MSVC/Windows SDK. Их нельзя считать проверенными или равными по готовности
прошедшему тесты Node backend. Для первого native build установить prerequisites,
добавить @tauri-apps/cli, уточнить launcher/cwd и закрепить Cargo.lock.

Пользовательские группы, запись пресетов, палитры, WS, трей, компактная нативная
оболочка, управление положением, полный профиль и релизный installer — последующие этапы.
В последующем этапе слоты «Работа/Вечер/Кино» реализованы и для реальных ламп: [редактор сценариев](SCENES.md).
Поддержка RGB в первом прототипе; расширенные каналы и метаданные ещё не подключены.
Preview хранит только реестр устройств версии 1, не полный профиль из domain/schema.

Никаких интеграций или изменений других RGB-программ и периферии.
