# Безопасность

Виджет управляет устройствами WLED в локальной сети. Не публикуйте в issues
Wi-Fi пароли, cfg.json, полный presets backup с личными данными, токены и
приватные логи. Перед отправкой диагностики проверьте её содержимое.

Приложение пока не выпущено; опубликованной матрицы поддерживаемых версий нет.
Чувствительные уязвимости сообщайте приватно через GitHub Security Advisory,
когда владелец включит эту возможность. Адрес и владелец репозитория ещё не заданы.
Не выдавать временный или несуществующий канал связи за действующий.
