# Участие в разработке

Прочитайте README и docs/ARCHITECTURE.md. Сейчас проект на этапе проектирования.
Перед добавлением зависимостей обсудите назначение и лицензию. Один PR — одна
завершённая задача с описанием поведения и выполненных проверок.

Пишите логи и тестовые фикстуры без реальных адресов и секретов. Для новых функций
WLED укажите ресурс API, версии и поведение при отсутствии capability.
UI не должен предполагать две лампы, одинаковые effect/preset ID или постоянную сеть.
Не добавляйте интеграции с другими RGB-программами.
