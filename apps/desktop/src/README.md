# Интерфейс WLED Desk | Widget

React/TypeScript. bridge.ts выбирает Tauri IPC либо локальный сервер preview.
Приложение работает только с добавленными WLED-устройствами. При пустом реестре
открывается добавление первой лампы; демонстрационного режима в интерфейсе нет.
DeviceStatus показывает имя и реальное состояние выбранных ламп.
