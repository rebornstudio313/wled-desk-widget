# Иконки Widget LED RGB — Контур 01

Выбран пользователем вариант 01. Оригинальная геометрия на сетке 24 × 24,
линия 1.9, скруглённые окончания и соединения. Питание, настройки и Peek —
голубой контур; работа — тёплое солнце, вечер — закат, кино — сиреневая хлопушка.
Цвет — цветовое кольцо с маркером. Лампа и связь дополняют общий набор.

Файлы SVG в `outline/` разрешено использовать по лицензии проекта MIT.
Рабочий React-набор находится в `apps/desktop/src/Icon.tsx` от корня проекта.
При правках геометрии обновлять оба представления. Эти векторные иконки
нарисованы для проекта; они не являются вырезками из изображения-макета.
