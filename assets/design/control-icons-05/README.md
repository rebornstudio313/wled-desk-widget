# 05 — Компактный баланс

Выбранное семейство иконок интерфейса WLED Desk | Widget. Оригиналы SVG,
сетка 24×24, толщина 1.65, скруглённые окончания и соединения. Основной размер
в интерфейсе 20 px; символ внутри бегунка питания 16 px, чтобы помещаться в него.
Полный и мини-виджет используют общий Icon.tsx. Значок приложения «Спектр» сохранён.
