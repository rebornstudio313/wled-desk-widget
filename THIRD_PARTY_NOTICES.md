# Сторонние компоненты и материалы

WLED Desk | Widget — независимый проект. Не является продуктом WLED или Espressif.
Код прошивки WLED не поставляется и не прошивается приложением; используется её сетевой API.

Прямые зависимости:

| Компонент | Лицензия |
|---|---|
| React / React DOM | MIT |
| Tauri / Tauri API / CLI | MIT или Apache-2.0 |
| Rust, Tokio, Reqwest, Serde, futures-util, tokio-tungstenite | лицензии upstream; см. метаданные Cargo |
| mdns-sd | Apache-2.0 или MIT; см. лицензию upstream в инвентаре |
| tauri-plugin-single-instance | MIT или Apache-2.0 |
| auto-launch | MIT |
| Vite | MIT |
| TypeScript | Apache-2.0 |
| pnpm | MIT |
| WebView2 Runtime | условия Microsoft; поставляется/скачивается отдельно установщиком |
| NSIS | лицензии upstream; применяется для упаковки, не включён в source archive |

Это обзор прямых зависимостей, не исчерпывающий список транзитивных лицензий.
Перед бинарным релизом сформировать полный отчёт по Cargo.lock и pnpm-lock.yaml
и приложить требуемые тексты лицензий. Эту работу нельзя считать завершённой только
по таблице выше. Версии закреплены lock-файлами; проверять их при обновлениях.

SVG-иконки и баннер с реальными снимками интерфейса подготовлены для проекта.
Изображения-концепты в assets/design созданы с помощью imagegen и помечены как
дизайн-исследования. Они не доказывают наличие показанных функций в бинарном релизе.
selected-reference.png — исходный пользовательский визуальный референс.
Код прежних локальных RGB-плагинов, конфигурации устройств и личные фото не включены.

Автоматический инвентарь: [DEPENDENCY-LICENSES.md](docs/DEPENDENCY-LICENSES.md), машиночитаемый JSON рядом. Тексты upstream сохранены в docs/licenses. Пункты needsReview требуют проверки перед публичным бинарным релизом.
